Flagship project

The Well-Architected Framework service guide for HPC

A service-neutral reliability and design guide for high-performance computing workloads on Microsoft Learn — authored and delivered end to end.

Krypton semester spotlight · authored end to end

The first guide bridging HPC deployment decisions to the WAF pillars

HPC customers had no reference connecting deployment choices to the Azure Well-Architected Framework’s reliability, performance, and cost pillars. I authored one — service-neutral, so architects get a consistent way to reason about reliability no matter how their cluster is assembled.

  • A reliability model built on criticality tiers, failure-mode analysis, and defined recovery targets.
  • Multi-region cluster deployment and performance-tuning guidance, shaped by customer capacity feedback.
  • HPC-specific decision trees and structured workload reference tables for fast evaluation.
  • Resolved a top-3 customer escalation theme and sped time-to-value across three key scenarios.
